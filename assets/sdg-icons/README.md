# SDG Icons Directory

This directory is intended for storing official UN SDG icons.

## Official UN SDG Icons

### Where to Download Official Icons:

1. **UN Communications Materials** (Recommended)
   - URL: https://www.un.org/sustainabledevelopment/news/communications-material/
   - Contains official SDG icons in 6 UN languages
   - Available formats: PNG, SVG, EPS
   - Includes both full-color and high-contrast versions

2. **UN SDG Action Campaign**
   - URL: https://sdgactioncampaign.org/resources/
   - Additional campaign materials and toolkits
   - Editable graphic assets

3. **Open SDG Platform**
   - URL: https://open-sdg.org/translations-un-sdg/
   - Icons in multiple languages
   - Both full-color and high-contrast versions

### File Naming Convention:
- `sdg-01-no-poverty.png` (SDG 1)
- `sdg-02-zero-hunger.png` (SDG 2)
- `sdg-03-good-health.png` (SDG 3)
- ... and so on for all 17 SDGs

### Usage Guidelines:
- Icons are free to use for non-commercial purposes
- Must not imply UN endorsement of products/services
- Follow UN branding guidelines
- Maintain color accuracy and proportions
